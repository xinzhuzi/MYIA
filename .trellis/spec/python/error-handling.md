# 错误处理约定

## 原则

- **fail-fast 于配置,隔离于运行**:YAML/凭据错误启动即拒(退出码 1);单源失败不拖垮品类其余源(pipeline 隔离)
- 错误必须**结构化**:字段路径 + 错误类 + 原因,供 `myia doctor`(JSON)与 agent 自修消费。禁止只有一句 str 的异常
- 引擎失败结构化上报:source / engine / 错误分类(风控类型/网络/解析),降级链据此决策
- 自定义规则求值(when 表达式)用白名单 AST,**永不 eval 任意代码**

## 退出码(CLI 契约,agent 与 CI 依赖)

| 码 | 含义 |
|----|------|
| 0 | 成功 |
| 1 | 配置错误(schema 拒载/明文凭据) |
| 2 | 采集全部失败 |
| 3 | 部分失败 |
