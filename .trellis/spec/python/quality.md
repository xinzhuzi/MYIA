# 质量与测试约定

## 测试

- pytest 全覆盖;引擎测试用**录制回放**(不真连,CI 不依赖外网与外部服务)
- 真实源 smoke 标注 skip-by-default(本地可选跑);真实推送/LLM 验证结果记任务日志,凭据永不进仓库
- 分类金测集:生产语料**脱敏摘要**做夹具(只留标题),私有语料零入库
- schema 每节缺省值单测;插件 YAML 互相校对 schema 完备度

## CI 红线

- pytest 全绿才可并;密钥扫描(明文凭据零容忍)
- 新增依赖必须论证(PRD 记录);核心保持 pip install 即跑

## 提交

- 功能提交信息用英文祈使句;一个子任务一个 PR 粒度;PRD 验收项逐条勾选后才能 finish
