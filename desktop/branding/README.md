# MYIA 品牌图标

**本目录是图标唯一事实源**(2026-10-02 仓库卫生:曾与 `myia-icon-1024.png`
逐字节相同的顶层副本 `desktop/app-icon.png` 已删除;`src-tauri/icons/` 是
`tauri icon` 生成物,随时可由本目录再生成)。

意象:眼睛 + 雷达虹膜 —— MYIA = "AI 替主人看着世界"(调研:eye 是情报领域经典意象,辅以雷达环表达扫描/监控)。
视觉:Linear 式深空蓝底,青(#22D3EE)→紫(#8B5CF6)渐变,瞳孔高亮 #67E8F9,右上紫色信号 blip。

2026-10-02 加厚重绘(主人反馈初版"太素";意象与色系不变,细节做厚,零 SVG
滤镜、纯渐变/形状实现,浏览器与 rsvg 渲染一致):

- 底:深空纵向渐变 + 青/紫双星云光晕 + 玻璃高光 + 暗角 + 渐变内描边;
- 星场:12 颗星 + 2 个四角星芒(只落四角,避开眼睛主体);
- 雷达:外环 + 虚线环 + N/E/S/W 刻度;扫掠为 5 级余辉扇形 + 亮边线 + 端点
  (旧版扫掠路径含 `512+139.8` 算术式,属无效路径语法,新版坐标全部实算);
- 眼:46px 低透明辉光层 + 24px 主描边双层;虹膜渐变盘 + 12 条纹理线;
  瞳孔暗芯 + 青 #22D3EE 光晕环 + #67E8F9 芯 + 白高光;
- 触点:虹膜环上紫色 blip(双扩散环)+ 外环左下青色小触点。

再生成:`rsvg-convert -w 1024 -h 1024 -o myia-icon-1024.png myia-icon.svg`
全尺寸图标集:`cd desktop && npx tauri icon branding/myia-icon-1024.png`
